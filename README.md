## 🌟 Highlights & Key Features

### 🧠 1. Interactive Neural Network Canvas
- Custom WebGL/HTML5 Canvas background running live particle physics and distance-based neural synaptic connections.
- Fully interactive with cursor attraction and repelling force fields.

### 🍱 2. 12-Column Parallax Bento Grid
- Mathematically calculated 3D tilt physics powered by Framer Motion (`useMotionValue` & `useTransform`).
- Dynamic radial cursor spotlight glow tracking exact mouse coordinates across glassmorphism surfaces.

### ⌨️ 3. Quick Command Palette (`⌘K` / `Ctrl+K`)
- Spotlight-style global search and command palette.
- Instantly jump to sections, filter tech stack, download the resume, or toggle theme accents using keyboard shortcuts.

### 📊 4. Real-Time Healthcare AI & ML Telemetry
- **Live ECG Waveform Monitor**: Real-time simulated patient telemetry monitor with dynamic heart rate and arrhythmia detection visualizer.
- **RAG Evaluation Matrix**: Live benchmark panel comparing Faithfulness (94.2%), Answer Relevance (96.8%), Context Precision, and Sub-120ms p95 latency.
- **Competence Radar Chart**: Interactive SVG radar graphing domain proficiency across LLMs, Multi-Agent Orchestration, MLOps, and Distributed Computing.

### 💻 5. Interactive AI Terminal & Playground
- Full interactive bash-like terminal with custom commands (`help`, `experience`, `stack`, `contact`, `clear`, `sudo`).
- Dynamic real-time theme customizer switching accent palettes (Emerald, Cyan, Violet, Amber, Rose) on the fly.

### 📑 6. High-Fidelity Resume Modal
- Embedded responsive viewer with one-click direct PDF download and tab-based skill matrices.

## 🚀 Quick Start (Run Locally)

### 1. Clone the repository
```bash
git clone https://github.com/saikrishnayemineni/sai-krishna-portfolio.git
cd sai-krishna-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Building for Production

```bash
# Generate optimized production bundle
npm run build

# Run the production server locally
npm start
```
